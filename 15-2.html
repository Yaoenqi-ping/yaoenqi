JavaScript 程序结构

任何复杂的程序，都可以拆解为顺序、选择与循环三种基本结构。下面用可交互的示例，逐一演示条件语句与循环语句的工作方式。

sequence if / switch for / while break / continue
01

三种基本结构

↓

顺序结构

程序按照书写顺序，从上到下逐条执行，是最基础的执行方式。

let price = 12;
let count = 3;
let total = price * count;
?

选择结构

根据条件是否成立，选择执行不同的代码分支。

if (total >= 30) {
  console.log("满减");
} else {
  console.log("原价");
}
↻

循环结构

在条件成立时重复执行同一段代码，避免重复书写。

for (let i = 1; i <= 3; i++) {
  console.log(i);
}
02

条件语句

if / else if / else

条件判断

输入 0 到 100 之间的分数，程序按区间输出对应等级。

if (score >= 90) {
  grade = "优秀";
} else if (score >= 60) {
  grade = "及格";
} else {
  grade = "不及格";
}

switch

多分支

选择星期几，程序通过 switch 匹配对应的安排。

switch (day) {
  case 1:
    plan = "整理本周计划";
    break;
  case 2:
    plan = "阅读与笔记";
    break;
  default:
    plan = "自由安排";
}
03

循环语句

for 循环

已知次数

适合已知循环次数的场景，点击按钮重新生成 1 到 10。

for (let i = 1; i <= 10; i++) {
  output.push(i);
}

while 循环

条件循环

当条件为真时持续执行，这里做一个 5 秒倒计时。

while (countdown > 0) {
  output.push(countdown);
  countdown--;
}
5

do...while 循环

至少执行一次

先执行循环体，再判断条件，因此至少执行一次。这里计算各位数字之和。

do {
  sum += n % 10;
  n = Math.floor(n / 10);
} while (n > 0);

break 与 continue

循环控制

遇到 3 的倍数用 continue 跳过，到达 15 时用 break 结束循环。

for (let i = 1; i <= 20; i++) {
  if (i % 3 === 0) continue;
  if (i === 15) break;
}
04

综合练习：FizzBuzz

条件与循环的组合

1 ~ 30

遍历 1 到 30：3 的倍数输出 Fizz，5 的倍数输出 Buzz，同时是 3 和 5 的倍数输出 FizzBuzz，其余输出数字本身。

if (i % 15 === 0) label = "FizzBuzz";
else if (i % 3 === 0) label = "Fizz";
else if (i % 5 === 0) label = "Buzz";
else label = i;
