03

遍历与变换：filter → map → reduce

数据处理管道

返回新数组 / 新值

先把不及格的成绩过滤掉，再给每个成绩加 5 分，最后求和。点击运行，观察每一步的数据变化。

const passed  = scores.filter(s => s >= 60);
const boosted = passed.map(s => s + 5);
const total   = boosted.reduce((sum, s) => sum + s, 0);
原始
filter
map
reduce
—

filter、map、reduce 都不会修改原数组；filter 保留满足条件的元素，map 把每个元素变成新值，reduce 把所有元素累积成一个结果。

04

查找与遍历

查找元素

indexOf / includes / findIndex

输入水果名，用三种方法分别查找，观察返回值和高亮位置。

找不到时，indexOf 与 findIndex 返回 -1，includes 返回 false。indexOf / includes 适合简单值查找，find / findIndex 可以传入回调，处理更复杂的判断。

forEach：逐个访问

没有返回值

按顺序对每个元素执行一次回调函数，适合做遍历输出，不会产生新数组。

arr.forEach((item, i) => {
  console.log(i, item);
});

连接、截取与拼接

join：数组变字符串

返回字符串

用分隔符把数组元素连接成一个字符串，原数组不受影响。

arr.join("，") →

分隔符可以是任意字符串；传入空字符串时，元素会直接连在一起。join 常用于把数组展示成一段文字。

concat：拼接数组

返回新数组

把多个数组拼在一起，返回新数组，a 和 b 都不会被修改。橙色方块来自数组 b。

slice：截取一段

不包含结束索引

拖动滑块选择 start 与 end，截取 [start, end) 区间的元素。slice 返回新数组，原数组保持不变。

start 1
end 4
arr.slice(1, 4) →

slice 的结束索引不包含在结果中；如果 end 小于 start，会得到空数组。绿色方块表示被选中的区间。

常用方法速查表

方法 作用 改变原数组 返回值
push(x) 在末尾添加一个或多个元素 是 新长度
pop() 删除最后一个元素 是 被删除的元素
unshift(x) 在开头添加一个或多个元素 是 新长度
shift() 删除第一个元素 是 被删除的元素
splice(i, n, ...) 从索引 i 开始删除 n 个，可插入新元素 是 被删除元素组成的新数组
reverse() 反转数组顺序 是 原数组（引用）
sort(fn) 对元素排序 是 原数组（引用）
slice(i, j) 截取 [i, j) 区间 否 新数组
concat(...) 拼接一个或多个数组 否 新数组
join(sep) 用分隔符连接成字符串 否 字符串
indexOf(x) 查找 x 第一次出现的索引 否 索引或 -1
includes(x) 判断数组是否包含 x 否 true / false
find(fn) 返回第一个满足条件的元素 否 元素或 undefined
findIndex(fn) 返回第一个满足条件的索引 否 索引或 -1
forEach(fn) 遍历每个元素 否 undefined
map(fn) 把每个元素映射成新值 否 新数组
filter(fn) 筛选出满足条件的元素 否 新数组
reduce(fn, init) 把所有元素累积成一个值 否 累积结果
