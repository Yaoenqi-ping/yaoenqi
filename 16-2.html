创建对象的三种常见方式

{ }

对象字面量

最常用：用花括号直接写出键值对，冒号分隔键和值，逗号分隔属性。

const person = {
  name: "小明",
  age: 18,
  city: "北京"
};
new

new Object()

先创建一个空对象，再逐个添加属性。写法较啰嗦，了解即可。

const person = new Object();

person.name = "小明";
person.age = 18;
person.city = "北京";
ƒ

构造函数

需要批量创建结构相同的对象时，用构造函数配合 new 生成实例。

function Person(name, age) {
  this.name = name;
  this.age = age;
}

const p = new Person("小明", 18);

04

遍历对象的属性

for...in 逐个访问

键名循环

for...in 会依次取出对象的每个属性名，再通过 obj[key] 拿到属性值。

for (const key in obj) {
  console.log(key, obj[key]);
}
点击按钮，按顺序输出每个键和值

Object.keys / values / entries

返回数组

这三个方法把对象的键、值或键值对转换成数组，方便继续使用数组方法处理。

keys
values
entries 
Object.keys(obj);    // ["name", "age", "city"]
Object.values(obj);  // ["小明", 18, "北京"]
Object.entries(obj); // [["name", "小明"], ...]

注意：for...in 拿到的是键名，要用 obj[key] 才能取到值；Object.keys 等方法返回的是新数组。

对象的方法与 this

方法：写在对象里的函数

this 指向 person

对象的方法可以读取同一个对象里的其他属性。点击按钮调用 greet，看看 this 指向谁。

点击按钮后，这里会出现方法的返回值

person.greet() 调用时，方法内部的 this 指向 person，因此 this.name 就是 person.name。

用 this 修改自身状态

计数器

每次调用 counter.inc()，方法通过 this.count++ 修改对象自己的 count 属性。

const counter = {
  count: 0,
  inc() {
    this.count++;
    return this.count;
  }
};
0

06

对象数组与 JSON

数组里的对象

3 位同学

实际开发中，经常把结构相同的对象放进数组，再用数组方法排序、筛选。

students.sort((a, b) => b.score - a.score) 通过对象的 score 属性比较分数。sort 会改变 students 数组的顺序。

JSON.stringify：对象转字符串

数据交换格式

JSON 是描述数据的文本格式，属性名必须用双引号。格式化后更易读，压缩后更省空间。

JSON.stringify 只序列化可枚举的属性；函数、undefined 会被忽略。用 JSON.parse 可以把字符串还原成对象。

07

对象常用操作速查表

操作 写法 说明
读取属性 obj.name / obj["name"] 点号访问；方括号里放字符串，可存放变量
修改属性 obj.name = "新值" 属性已存在时，更新它的值
新增属性 obj.hobby = "篮球" 属性不存在时，自动新增
删除属性 delete obj.name 删除整个键值对，而不是把值设为 undefined
检测属性 "name" in obj 返回布尔值，判断属性是否存在
所有键 Object.keys(obj) 返回键名组成的数组
所有值 Object.values(obj) 返回属性值组成的数组
键值对 Object.entries(obj) 返回 [键, 值] 组成的二维数组
合并对象 Object.assign({}, a, b) 把多个对象合并成一个新对象
展开复制 { ...a, ...b } 用展开运算符复制或合并对象
序列化 JSON.stringify(obj) 对象转成 JSON 字符串
解析 JSON.parse(str) JSON 字符串还原成对象
冻结对象 Object.freeze(obj) 禁止新增、修改和删除属性
