Web 前端的长度单位

CSS 中用于定义尺寸的各类长度单位演示

一、绝对长度单位

绝对长度单位是固定的，不随其他因素变化（像素在不同设备上可能受 DPI 影响）。

5cm（厘米）
50mm（毫米）
2in（英寸）
100pt（点，1pt = 1/72 英寸）
10pc（派卡，1pc = 12pt）
200px（像素）

二、相对长度单位

相对长度单位基于其他尺寸（如父元素字体、根元素字体、视口等）动态计算。

em —— 相对于当前元素字体大小

父容器字体 20px，子元素 width: 5em = 100px

5em（父字体 20px × 5 = 100px）

rem —— 相对于根元素（html）字体大小

根字体默认 16px，width: 5rem = 80px

5rem（根字体 16px × 5 = 80px）

% —— 相对于父元素

父容器宽 400px，子元素 width: 50% = 200px

50%（父宽 400px 的 50%）

vw / vh —— 相对于视口

1vw = 视口宽度的 1%，1vh = 视口高度的 1%

20vw（视口宽度 20%）
15vh（视口高度 15%）

三、单位对照表

单位 名称 类型 参考基准
px像素绝对设备像素（最常用）
cm厘米绝对1cm = 37.8px
mm毫米绝对1mm = 0.1cm
in英寸绝对1in = 2.54cm = 96px
pt点绝对1pt = 1/72in
pc派卡绝对1pc = 12pt
em相对字体相对当前元素字体大小
rem根相对字体相对根元素字体大小
%百分比相对父元素对应属性
vw视口宽度相对视口宽度的 1%
vh视口高度相对视口高度的 1%
vmin视口较小边相对vw 与 vh 中较小者
vmax视口较大边相对vw 与 vh 中较大者
